# Contributing

**This repository does not accept external contributions.** Pull requests and issues from third parties will be
closed without review. The repository is maintained solely by [@ymchandra](https://github.com/ymchandra)
(see `.github/CODEOWNERS`).

* Licensing or takedown requests: see "Legal / Attribution" in [README.md](README.md).
* Security issues: contact the maintainer privately (see README for the contact placeholder), do not file public reports.
* You are welcome to fork the project under the terms of [LICENSE](LICENSE) (code) and
  [LICENSE-DATA.md](LICENSE-DATA.md) (data).
